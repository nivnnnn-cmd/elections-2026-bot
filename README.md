# אמרו · הצביעו

- האתר הוא קבצים פשוטים (HTML, CSS ו-JavaScript). כל החישוב קורה בדפדפן של המשתמש. שום דבר לא נשמר ולא נשלח.
- נתוני ההצבעות לקוחים מהמאגר הרשמי של הכנסת (Knesset OData).
- `tests.html` מריץ בדיקות על החישוב.
